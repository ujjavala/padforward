# PadForward — Product

## Insight

> There may already be someone nearby willing to help. The problem is that the
> person who needs help shouldn't have to ask.

## Core loop

```
NEED → find a pad → someone helped you → when able → DONATE
     → AI finds highest need → station restocked → someone else finds it → NEED
```

## Users

- **A — Person who needs a pad**: privacy, speed, no signup. Primary action: *Find a Pad*.
- **B — Donor**: easy donation, confidence it's useful, impact. Primary action: *Donate Pads*.
- **C — Community Champion**: adopt, verify, restock, report. Primary action: *Adopt a Station*.

## Principles

1. **Privacy first** — no account to receive, no public requests, no identity exposure.
2. **Speed first** — need→directions in a few taps, one-handed.
3. **No awkward conversations** — you don't have to ask a stranger.
4. **Generosity without guilt** — "when you're able, help someone else"; never pressure.
5. **Transparency** — supply is Plenty/A few/None/Unknown with timestamps and confidence, never pretend-exact.

## Impact language

We say *"Your 20 pads are now available through the community network"* — never
unsupported claims like *"your pads helped 20 people."* All demo figures are
labelled **Demo network**.

## Non-goals

No e-commerce, marketplace, social network, messaging, crypto payments,
period/fertility tracking, or medical advice.
