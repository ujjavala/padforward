# Seed data

Demo network data is seeded automatically by the API on first startup
(see `services/api/app/seed.py`). It creates six clearly-labelled
**Demo Community Points** at real Sydney station coordinates:

- Central Station
- Town Hall Station
- Wynyard Station
- Museum Station (seeded as the CRITICAL demo station)
- Redfern Station
- Central Bus Interchange

Supply figures are demonstration data and do not represent real-world
station inventory.
